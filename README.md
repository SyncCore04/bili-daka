# 📺 BiliDaka · 分P研习录

> 一个运行在浏览器中的 B站多视频分P学习进度批量打卡工具。

管理多个 B站教程视频的分P学习进度，支持逐P勾选、理解程度标记、刷课次数统计、批量操作和本地数据持久化。专为跟练长系列教程（如几百P的编程课）设计。

---

## ✨ 功能特性

- **多视频分表管理**：每个视频独立一张表格，标题、BV号、进度一目了然
- **逐P打卡**：复选框标记是否看完，下拉选择理解程度（懂/半懂/不懂），数字记录刷了几遍
- **批量操作**：一键全部已看/未看，或按分P序号范围批量设置是否看完、理解程度、刷数
- **实时统计看板**：总课时、已完成数、完成率，每个视频独立进度条
- **本地持久化**：数据保存在同目录 `bili_checklist.csv`，启动自动加载，手动保存
- **异常容错**：网络超时、BV号无效、私密视频、CSV损坏均有明确提示，不崩溃

## 🛠 技术栈

| 层级 | 技术 |
|---|---|
| 语言 | Python 3.10+ |
| Web框架 | [Streamlit](https://streamlit.io/) |
| 数据处理 | pandas |
| 网络请求 | requests |
| 数据源 | B站公开 API `x/web-interface/view` |

> Streamlit 采用"代码即界面"范式，纯 Python 编写，无需手写 HTML/CSS/JS，前端由运行时动态渲染。

## 🚀 快速开始

### 环境要求

- Python 3.10 及以上
-  pip

### 安装依赖

```bash
pip install streamlit pandas requests
```

### 启动

**方式一：命令行**

```bash
streamlit run app.py
```

**方式二：Windows 一键启动**

双击 `启动.bat`。

浏览器会自动打开 `http://localhost:8501`。

## 📖 使用说明

### 添加视频

1. 在左侧侧边栏粘贴 B站视频链接（如 `https://www.bilibili.com/video/BV1XW4y1Z789`）或直接输入 BV号
2. 点击「抓取并添加」，自动获取该视频所有分P标题
3. 重复添加可管理多个视频，系统自动去重

### 打卡学习

- 在对应视频的表格中勾选「是否看完」
- 「理解程度」下拉选择当前掌握情况
- 「刷了几遍」记录重复学习次数
- 「备注」可填写任意 Markdown 笔记

### 批量操作

每个视频卡片上方提供：

- **✅ 全部已看** / **↩️ 全部未看**：一键操作整个视频
- **⚙️ 批量设置**：指定分P范围（从第P到第P），组合设置是否看完、理解程度、刷数

### 保存进度

点击表格下方的 **💾 保存当前进度**，将所有修改写入 `bili_checklist.csv`。

## 💾 数据存储

所有数据保存在同目录下的 `bili_checklist.csv`（UTF-8 with BOM，Excel 可直接打开），包含 8 列：

| 列名 | 类型 | 说明 |
|---|---|---|
| 视频标题 | 文本 | 自动填充，不可编辑 |
| BV号 | 文本 | 自动填充，不可编辑 |
| 分P序号 | 整数 | 自动填充，不可编辑 |
| 分P标题 | 文本 | 自动填充，不可编辑 |
| 是否看完 | 布尔 | 用户勾选 |
| 理解程度 | 文本 | 懂 / 半懂 / 不懂 |
| 刷了几遍 | 整数 | 默认 0 |
| 备注 | 文本 | 用户自由填写 |

## ⚠️ 注意事项

- **断网可用**：已添加视频的打卡、编辑、保存均为本地操作，无需联网；仅「抓取并添加新视频」需要访问 B站 API
- **CSV 占用**：保存时若 CSV 正被 Excel 打开会写入失败，请关闭后重试
- **API 限制**：B站公开接口无需鉴权，但频繁请求可能被限流
